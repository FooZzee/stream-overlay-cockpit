# 🎮 Справочник интерактивных команд и API разработчика

> **ETS2 / ATS Stream Overlay Cockpit v0.0.2**  
> Полное техническое руководство по интерактивным командам чата, триггерам событий телеметрии и методам консольного тестирования оверлея.

## 1. Интерактивные команды Twitch-чата

Обработка команд чата выполняется модулем `assets/js/ets2-chat.js`. Настройки прав доступа, спам-фильтра и таймеров задержки настраиваются в секции `chatCommands` конфигурационного файла `config.js`.

| Команда | Алиас | Описание и возвращаемые данные |
| :--- | :--- | :--- |
| `!грузик` | `!cargo` | Название перевозимого груза, масса в тоннах и особые категории (хрупкий, опасный ADR). |
| `!рейс` | `!job` | Город отправления, город назначения, оставшаяся дистанция в км/милях и плата за доставку. |
| `!тягач` | `!truck` | Марка и модель тягача, текущая передача КПП и статус круиз-контроля. |
| `!урон` | `!damage` | Детальный износ тягача, полуприцепа и перевозимого груза в процентах. |
| `!топливо` | `!fuel` | Текущий объём топлива в баке (литры / галлоны), процент бака и расчётный запас хода. |
| `!скорость` | `!speed` | Текущая скорость тягача и ограничение скорости на данном участке дороги. |
| `!погода` | `!weather` | Текущее игровое время суток и погодные условия (ясно, переменная облачность, дождь). |
| `!помощь` | `!help` | Вывод краткого списка доступных команд в чат трансляции. |

> [!NOTE]
> Команды доступны как на русском языке (`!рейс`), так и на английском (`!job`). Для предотвращения флуда в чате по умолчанию активен кулдаун 5 секунд между запросами от одного зрителя.

## 2. Консольные команды разработчика (F12 в браузере)

Для тестирования анимаций, геометрии и поведения оверлея без запущенного симулятора откройте панель разработчика (F12) в браузере и используйте методы глобального объекта `window`:

| JavaScript метод | Назначение |
| :--- | :--- |
| `window.setWebcamAspect('4:3')` | Мгновенно переключает рамку веб-камеры в стандартный формат `4:3` (325×244 px). |
| `window.setWebcamAspect('16:9')` | Мгновенно переключает рамку веб-камеры в широкоформатный `16:9` (384×216 px). |
| `window.testStreamAlert('donate', 500, 'Alex', 'Счастливого пути!')` | Запуск тестовой карточки доната с последующим эффектом разлёта на осколки. |
| `window.testStreamAlert('sub', null, 'Dmitry', 'Подписка 6 месяцев')` | Запуск тестового уведомления о платной подписке на канал. |
| `window.testStreamAlert('follow', null, 'Sergey')` | Запуск тестового уведомления о новом фоллове. |
| `window.testStreamAlert('raid', 45, 'TruckerPro')` | Запуск тестового уведомления о рейде канала. |

```javascript
// Пример переключения рамки веб-камеры:
window.setWebcamAspect('16:9');

// Пример вызова оповещения о донате:
window.testStreamAlert('donate', 1000, 'Дальнобойщик', 'Ни гвоздя, ни жезла на трассе!');
```

## 3. URL-параметры оверлея для OBS Studio

При добавлении оверлея в OBS Studio в качестве источника типа «Браузер» вы можете задавать конфигурационные флаги прямо через адресную строку URL:

| URL параметр | Пример использования | Назначение и поведение |
| :--- | :--- | :--- |
| `?cam=4x3` | `ets2-desktop.html?cam=4x3` | Принудительно устанавливает пропорции рамки веб-камеры `4:3`. |
| `?cam=16x9` | `ets2-desktop.html?cam=16x9` | Принудительно устанавливает пропорции рамки веб-камеры `16:9`. |
| `?test=1` | `ets2-desktop.html?test=1` | Включает демонстрационный режим с циклической генерацией тестовых данных телеметрии. |
| `?lang=ru` | `ets2-desktop.html?lang=ru` | Принудительно переключает интерфейс оверлея на русский язык. |
| `?lang=en` | `ets2-desktop.html?lang=en` | Принудительно переключает интерфейс оверлея на английский язык. |

> [!TIP]
> **Рекомендации по настройке источника Браузер в OBS Studio:**
> * **Ширина и высота:** задайте ровно `1920` × `1080` (для Full HD) или `2560` × `1440` (для 2K QHD).
> * **Частота кадров:** установите `60 fps` для плавной анимации стрелок и разлёта осколков.
> * **Управление памятью:** снимите флажок «Завершать сеанс, когда источник становится невидимым», чтобы не прерывать сессионную статистику рейса при переключении сцен.
